# Fixed-input, global-Morton wire-layout sweep

All sizes are bytes. These are offline wire-renaming experiments, not production policy changes. Period 6, all circuit input IDs (including private witnesses and wire 0), external outputs, geometry, term multiset, canonical global Morton traversal, and the stock LFC2 segmenter (window 32) are fixed. Some policy labels produce identical layouts. No size-based per-circuit selection is implemented.

## Level-3 screening: 73 policies on three fixtures

`bip1` includes constant-1 vertices in per-layer connectivity; `bip0` excludes all known copies of 1. Components use the minimum graph vertex ID (input namespace before output namespace). `whole` ignores original circuit inputs and constant-only wires for whole-circuit connectivity. Within a group, `old` preserves original order, `fanin` sorts exact incoming term lists, `shape` uses local input ranks, and the remaining names describe producer/consumer scores. `*3` uses three forward/backward rounds. Unprefixed methods are global. Bit transforms operate only on complete aligned blocks of 2^k wires; partial tails and all circuit inputs are unchanged. Constant placement moves only intermediate copies, not input wire 0. `swap` transposes the existing constant position with the target rather than shifting the other wires.
