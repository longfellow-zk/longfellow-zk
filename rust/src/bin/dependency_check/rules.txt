# Allowed dependencies between components, checked by
#   cargo run --release --features tooling --bin dependency_check
# A component is a module path (`runtime/v2/zk`): a file belongs to the
# longest component its module path starts with. A component with components
# below it owns only its root file (`src/runtime/v2.rs`), so every other
# module needs a component of its own. Each line `component: dependencies...` lists
# every component the component's files may use; an edge missing here fails
# the check, and so does a component without a line. Keep the rules acyclic.
# The file graph itself must be acyclic too: any file cycle fails.
# `--current` prints the current graph in this format.
#
# Notes on individual edges:
# - mdoc/circuits -> mdoc/testcases: test
#   fixtures in src/mdoc/circuits/cbor/test_utils.rs, compiled only with `testonly`.
# - runtime/v2/proto/tags has no dependencies, so the transcript can name the
#   message tag registry without depending on the rest of the proof contract
#   (transcript I6, proto I7). Its parent then owns only `proto.rs`, so every
#   proto module has its own line.
